## 2. Objetivo da Task
Implementar a comunicação RPC no front-end (`BankTransactionRepository`), cadastrar no GetIt e construir o componente `ImportOfxDialog` integrado ao card de contas bancárias para seleção de arquivo `.ofx`, exibição de resumo de conferência e confirmação de importação.

## 4. Detalhes de Implementação
- [x] Adicionar chaves de internacionalização no `app_pt.arb` e `app_en.arb` (título de importação, seleção de arquivo, totalizadores de crédito/débito, contadores de novos vs duplicados, aviso de conta divergente) e rodar `flutter gen-l10n`.
- [x] Criar `IBankTransactionRepository` e `BankTransactionRepository` com:
  - `Future<OfxPreviewResult> previewOfx(String bankAccountId, String ofxContent)`
  - `Future<List<BankTransaction>> importOfx(String bankAccountId, String ofxContent)`
  - `Future<List<BankTransaction>> listTransactions(String bankAccountId, {bool? isReconciled})`
  - `Future<BankTransaction> reconcile(String transactionId, String financialEntryId)`
- [x] Registrar o repositório em `repositories_injections.dart`.
- [x] Criar `ImportOfxDialog` como `StatefulWidget` (sem funções que retornam widgets):
  - Botão para selecionar arquivo `.ofx` (usando `file_picker` ou `UniversalFilePicker`).
  - Ao carregar o arquivo, chama `previewOfx`.
  - Se `isAccountMatched == false`, exibe alerta em vermelho destacando que o arquivo pertence a outra agência/conta e mantém o botão "Confirmar Importação" desabilitado.
  - Se `isAccountMatched == true`, exibe o resumo com `DSTokens` (período, créditos, débitos, transações novas) e habilita o botão de confirmação.
  - Ao confirmar, invoca `importOfx`, exibe `SnackBar` de sucesso e fecha o diálogo com retorno `true`.
- [x] Atualizar `BankAccountCard` adicionando o botão de importação de OFX.
